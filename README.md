# RNA-seq analysis of dermal aging

Analysis code for the manuscript on transcriptional changes in human dermal
fibroblasts during skin aging.

## Contents

- `1_bulk_rnaseq/`: bulk RNA-seq of human dermis, from raw reads to
  differential expression, co-expression modules, TF screening and GENIE3
  regulatory networks.
- `2_public_scrna/`: BayesPrism deconvolution of bulk samples against a public
  healthy skin fibroblast scRNA-seq reference.

## Requirements

Analyses were run with R 4.2.0.

- Trim Galore 0.6.10, HISAT2 2.2.1, samtools and Subread featureCounts 2.0.3.
- R packages: DESeq2 1.38.3, Mfuzz 2.70.0, clusterProfiler 4.6.2, GENIE3
  1.20.0, RcisTarget 1.18.2, BayesPrism 2.2.3, org.Hs.eg.db 3.16.0, dorothea
  1.10.0, decoupleR 2.4.0, Seurat 4.3.0, openxlsx 4.2.8, arrow 14.0.0.2 and
  dplyr 1.2.1.

## Data

Raw sequencing data are not included. Place FASTQ files in
`1_bulk_rnaseq/data/fastq/` using the sample names listed in
`1_bulk_rnaseq/config.R`.

The public healthy skin fibroblast reference is described in the manuscript.
Place its 10X-format export in `2_public_scrna/data/seurat_input/`, with
`matrix.mtx.gz`, `barcodes.tsv.gz`, `features.tsv.gz`, `metadata.csv` (celltype
column), `umap.csv` and `scvi.csv`.

The RcisTarget motif databases used by scripts 19 and 20 are downloaded
separately from https://resources.aertslab.org/cistarget/ and placed under
`1_bulk_rnaseq/data/cistarget/`.

## Usage

Run each subproject from its own directory, in numeric order.

Bulk RNA-seq:

```bash
cd 1_bulk_rnaseq
bash 01_trim_align_count.sh all
bash 02_qc.sh
Rscript 03_expression_matrix.R
Rscript 04_mfuzz_cluster.R
Rscript 05_mfuzz_go.R
Rscript 06_deg_deseq2.R
Rscript 07_deg_go.R
Rscript 08_module_export.R
Rscript 09_tf_screen.R
Rscript 10_filter_coding.R
Rscript 11_genie3_network.R
Rscript 12_genie3_hub.R
Rscript 13_genie3_cytoscape.R
Rscript 14_genie3_tf_influence.R
Rscript 15_genie3_diffhub.R
Rscript 16_genie3_target_go.R
Rscript 17_dorothea_target_go.R
Rscript 18_coexpression_go.R
Rscript 19_tf_motif_targets.R
Rscript 20_motif_target_go.R
```

Deconvolution:

```bash
cd 2_public_scrna
Rscript 01_build_seurat.R
Rscript 02_run_bayesprism.R
```

## Output

All scripts write to `results/` inside their subproject directory. The
deconvolution cell-fraction table is committed as
`2_public_scrna/results/theta_cell_fractions.tsv`; all other results are
regenerated by
the pipeline and excluded from the repository.
